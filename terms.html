Usage terms. Keep a backup of original saves.

Universal RPG Maker Save Editor runs locally under the repository MIT license as a client-side editor for personal game saves and JSON database tables.

Backups before writing

Keep an unmodified copy of every save file or project JSON before replacing files in your game folder. Universal RPG Maker Save Editor exports clean modified files separately and includes an original backup download option.

Supported formats

Format support covers standard RPG Maker MZ, MV, VX Ace, VX, XP, and Naninovel save archives, plus unencrypted Ren'Py inspection and RPG Maker JSON database files. Games using custom native encryption or anti-tamper plugins may reject edited files.
