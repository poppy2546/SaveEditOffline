Local file processing. Zero server uploads.

Every save file and JSON table you drop into Save Studio stays inside browser memory on your device.

What stays on your computer

Save decoding, Marshal parsing, LZString decompression, Pako inflate operations, and JSON formatting execute locally in JavaScript. No save contents, file names, character stats, or database edits leave your browser tab.

Cookies and tracking

Save Studio sets no analytics beacons, advertising cookies, or account trackers. Reloading the tab clears loaded save data unless you save a modified copy back to disk.

Fonts and third-party requests

Static typography sheets load from Google Fonts when served over HTTP. All scripts, save parsers, and interface styles ship directly from the application directory.
